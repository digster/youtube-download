## Remove custom playlists

- Shelf previously returned HTTP 405 for playlist removal. Custom library
  pages now offer **Remove playlist** with a named confirmation. Success
  returns to the overview. YouTube playlists have no removal control and the
  API checks their saved source before it changes any rows.
- Removal clears membership, queued jobs and unshared archive checks in one
  transaction. A running download or metadata worker must release the playlist
  first. Completed media and partial files stay on disk. Finder keeps its
  cooldown if an in-flight response arrives after removal.
- All 256 tests passed, including coverage for shared IDs, repeat removal,
  paused workers still stopping, database rollback and archive lookup races.
  Chromium checked keyboard dismissal, error recovery and successful removal.
  A phone-width Chromium run created and removed a custom playlist against
  an isolated Shelf server and verified the synced playlist was still present.
